# Landing imagery

## `moon-lro.jpg`

- **Subject:** full Moon seen by NASA's Lunar Reconnaissance Orbiter (LRO).
- **Source:** NASA Image and Video Library, image
  [`GSFC_20171208_Archive_e001861`](https://images.nasa.gov/details/GSFC_20171208_Archive_e001861).
- **Credit:** NASA / GSFC / Arizona State University (LRO).
- **Usage:** NASA media are generally not copyrighted in the United States; NASA
  does not endorse this project. The image is used as a decorative hero asset and
  is credited in the landing page.
- **Processing:** downscaled to 1400×1400 and re-encoded as progressive JPEG
  (quality 82) for the web.
