# Pre-computed ephemerides: Sun and Earth from lunar south-pole sites

These files are the Horizons-derived inputs of the L-SEA site-selection tool.
The deployed application is static, so it never calls JPL Horizons at runtime;
it reads these pre-computed files instead (the Vite dev server exposes an
optional `/nasa/horizons` proxy for live experiments only).

Generated by [`scripts/nasa/fetch-horizons.mjs`](../../../scripts/nasa/fetch-horizons.mjs)
from the **real JPL Horizons API** (DE441 solar-system ephemeris). Do not edit
these files by hand; re-run the script instead.

## Shape (`<site-id>.json`)

```json
{
  "siteId": "haworth",
  "site": { "lat": -86.7, "lon": 336.3 },
  "moonRadiusM": 1737400,
  "source": "NASA/JPL Horizons API (DE441), topocentric apparent az/el",
  "center": "coord@301 (Moon), GEODETIC site coordinates, airless (no refraction)",
  "units": {
    "az": "degrees east of selenographic north, 0..360",
    "el": "degrees above local horizon"
  },
  "generated": "2026-11-14T10:35:23.667Z",
  "apiVersion": "1.2",
  "range": { "start": "2026-11-01T00:00:00Z", "end": "2026-12-31T23:30:00Z" },
  "stepMinutes": 30,
  "sampleCount": 2928,
  "samples": [
    {
      "time": "2026-11-01T00:00:00Z",
      "sun":   { "az": 308.719, "el": 3.524 },
      "earth": { "az": 27.782,  "el": 5.862 }
    }
  ]
}
```

### Semantics

- **Time** is UTC ISO-8601 with `Z`. The first sample is `2026-11-01T00:00:00Z`
  and the last is `2026-12-31T23:30:00Z`; exactly **2928 samples** at a fixed
  **30-minute** cadence, no gaps. Interpolate linearly between samples.
- **Azimuth** is the apparent topocentric azimuth measured clockwise from
  **selenographic (true) north**, in degrees, `0..360` (0 = north, 90 = east).
  It is *not* rebased to any local or map-specific reference.
- **Elevation** is the apparent topocentric elevation above the local horizontal
  plane in degrees, negative below the horizon. Horizons is queried as an
  **airless** observer (no atmospheric refraction), which is correct for the Moon.
- **Origin of the frame**: JPL Horizons `CENTER='coord@301'`, i.e. the observer
  is a GEODETIC site on the Moon (NAIF body 301), not the geocentre. The site
  coordinates come from `public/data/pois.json`.
- **No light-time or libration post-processing was applied by L-SEA**: the
  numbers are Horizons' apparent astrometric-style topocentric values for the
  requested site, exactly as returned by the API.

## Regenerating

```bash
node scripts/nasa/fetch-horizons.mjs            # skip files that already exist
node scripts/nasa/fetch-horizons.mjs --force    # re-query everything
node scripts/nasa/fetch-horizons.mjs --only=haworth
node scripts/nasa/fetch-horizons.mjs --dry-run  # print the exact query URLs
```

The script sends one request at a time with a 1.5 s delay (configurable with
`--delay=<ms>`), identifies itself in the `User-Agent`, and retries HTTP 429/5xx
with exponential backoff. A full run is 20 requests (2 bodies x 10 sites).
